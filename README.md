# 🎓 Student Performance Prediction using Machine Learning

## 📌 Project Overview
This project predicts students' final academic performance (G3) using Machine Learning. The dataset contains demographic, social, family, and academic information about students. The project follows a complete machine learning workflow, including data preprocessing, exploratory data analysis (EDA), model training, prediction, and evaluation.

## 🎯 Objective
The objective of this project is to analyze factors affecting student performance and build a predictive model that estimates the final grade (G3).

## 📂 Dataset
- **Dataset Name:** Student Performance Dataset
- **Source:** Kaggle
- **File Used:** `Maths.csv`

### Features
The dataset includes:
- School
- Gender
- Age
- Address
- Family Size
- Parent's Education
- Parent's Occupation
- Study Time
- Previous Failures
- Extra Educational Support
- Internet Access
- Free Time
- Absences
- First Period Grade (G1)
- Second Period Grade (G2)
- Final Grade (G3)
